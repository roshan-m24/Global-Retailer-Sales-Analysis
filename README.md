# Global-Retailer-Sales-Analysis

Transformed retail sales data into an interactive executive dashboard to analyze business performance and support data-driven decision-making.

## KEY FEATURES:
✔ KPI Cards (Sales, Profit, Orders, Customers & Average Order Value)
✔ Interactive Slicers for dynamic analysis
✔ Sales Trend Analysis
✔ Geographic Sales Analysis
✔ Market Performance Analysis

## 🛠 Tools & Technologies:
Microsoft Power BI
Power Query
SQL
DAX
Microsoft Excel with SQL
